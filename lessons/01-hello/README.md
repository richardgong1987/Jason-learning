# Lesson 1: Run Your First Agent

**Goal:** understand an initial goal and a matching plan. This lesson is complete when you see the greeting and can change it.

## Run

From the repository root:

```bash
cd lessons/01-hello
jason hello.mas2j
```

Expected key output:

```text
[robot] Hello! I am a Jason agent.
```

Logs and prefixes may differ between versions.

## Read the Code

Open `robot.asl`:

```prolog
!start.

+!start
    <- .print("Hello! I am a Jason agent.").
```

- `!start.` declares an initial achievement goal.
- `+!start` matches the event generated by that new goal.
- `<-` introduces the plan body: the steps to execute.
- `.print` is a built-in internal action.
- The final `.` ends the complete plan.

`start` is a name we chose. It is not a special Jason entry-point keyword.

The `.mas2j` configuration declares an agent named `robot`. Its source code is in `robot.asl`.

## Exercise

Change the message to `Hello, Hanjin!`. Stop the current system, run it again, and check that the output changed.

## Explain It Aloud

> My agent has an initial goal called start. When that goal creates an event, Jason selects a matching plan. The plan prints a greeting.
